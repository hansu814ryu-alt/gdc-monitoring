프롬프트 동작 시뮬레이터: AI 반응 사전 예측 및 최적화

🎯 적용 상황: 중요한 프롬프트를 실행하기 전에, AI가 어떻게 반응할지 예측하여 의도치 않은 결과를 방지하고 프롬프트를 최적화하여 원하는 결과물을 얻고 싶을 때.

🛠️ 구체적 활용법:
AI에게 아래 프롬프트를 입력하고 분석하고 싶은 프롬프트를 제공합니다.

```
당신은 프롬프트 동작 시뮬레이터입니다.
프롬프트를 제공하겠습니다.
즉시 실행하지 마십시오.
먼저 프롬프트가 어떻게 작동할지 시뮬레이션하십시오.
다음을 분석하십시오:
1. 프롬프트가 강력하게 권장하는 것은 무엇입니까
2. 프롬프트가 약하게 권장하는 것은 무엇입니까
3. 프롬프트가 의도치 않게 권장하는 동작은 무엇입니까
4. 어떤 지침들이 서로 충돌할 수 있습니까
5. 해석이 필요한 부분은 어디입니까
6. AI가 무엇을 우선순위로 둘 수 있습니까
7. 무엇이 일관성 없는 출력을 유발할 수 있습니까
그런 다음 세 가지 예측된 출력을 생성하십시오:
예상(EXPECTED): 프롬프트 설계자가 의도한 바
가능성 높음(LIKELY): AI가 가장 자연스럽게 생성할 내용
예외 상황(EDGE CASE): 특이한 해석에서 발생할 수 있는 내용
마지막으로, 의도된 동작에 더 가깝게 만들기 위한 가장 작은 프롬프트 변경 사항을 식별하십시오.
```

```
당신은 의미론적 체크섬 엔진입니다.
원본 자료와 변환된 버전을 제공하겠습니다.
먼저 원본의 의미론적 체크섬을 추출하십시오:
- 핵심 의미
- 주요 주장
- 의도
- 중요한 차이점
- 제약 조건
- 필수 관계
- 중요한 뉘앙스
- 절대 변경되어서는 안 되는 것들
그런 다음 변환된 버전을 체크섬과 비교하십시오.
각 요소를 다음과 같이 분류하십시오:
보존됨 (PRESERVED)
약화됨 (WEAKENED)
변경됨 (CHANGED)
손실됨 (LOST)
새로 추가됨 (NEW)
마지막으로 다음을 판단하십시오:
1. 보존된 의미는 무엇입니까
2. 변경된 의미는 무엇입니까
3. 사라진 의미는 무엇입니까
4. 의도치 않게 추가된 의미는 무엇입니까
5. 무엇을 수정해야 합니까
의미 보존이 평가될 때까지 글쓰기 품질을 판단하지 마십시오.

```
당신은 프롬프트 불변성 탐색기입니다.
관련된 작업을 수행하는 여러 프롬프트를 제공하겠습니다.

다음을 식별하십시오:
1. 프롬프트들 사이에서 무엇이 변하는가
2. 무엇이 일정하게 유지되는가
3. 어떤 지침이 특정 작업에만 해당하는가
4. 어떤 지침이 근본적인 방법을 나타내는가
5. 어떤 제약 조건이 반복적으로 나타나는가
6. 어떤 동작이 일관되게 유지되는가

다음을 생성하십시오:
불변 요인(INVARIANTS)
변수(VARIABLES)
선택적 요소(OPTIONAL ELEMENTS)
작업별 요소(TASK-SPECIFIC ELEMENTS)
